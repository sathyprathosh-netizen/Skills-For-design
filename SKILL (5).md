# SEO Optimization Skill

Follow `GLOBAL-OPERATING-SYSTEM.md`. Before SEO work, complete the identity gate and establish audience, target market, language, conversion goal, and whether local SEO applies.

## 1. SEO discovery

- [ ] Identify product/service, target audience, business model, and conversion.
- [ ] Confirm country, language, and search market.
- [ ] For local SEO, ask for the real business name, address/service area, phone, hours, categories, and actual locations served.
- [ ] Inspect current site structure, robots.txt, sitemap, canonical tags, indexation, analytics, and Search Console if available.
- [ ] Review competitors and search results for intent—not to copy their wording.
- [ ] Separate informational, commercial investigation, transactional, and navigational intent.
- [ ] Do not promise rankings or fabricate search volume / difficulty.

## 2. Keyword and intent mapping

- [ ] Build topic clusters around real services and user problems.
- [ ] Map one primary intent to each page.
- [ ] Avoid multiple pages competing for the same query without a clear reason.
- [ ] Use natural variants and entities; do not keyword-stuff.
- [ ] Include location modifiers only where the business genuinely serves that location.
- [ ] Prioritize useful pages over thin keyword doorway pages.
- [ ] Record keyword, intent, target URL, supporting topics, and desired action.

## 3. Technical SEO

- [ ] Ensure important pages are crawlable and indexable.
- [ ] Use a clean, logical URL structure.
- [ ] Create and submit an accurate XML sitemap.
- [ ] Configure robots.txt without accidentally blocking important resources.
- [ ] Use self-referencing or correct canonical URLs.
- [ ] Handle redirects, 404s, pagination, and duplicate URLs deliberately.
- [ ] Ensure mobile usability and stable rendering of meaningful content.
- [ ] Use valid structured data only when page content qualifies.
- [ ] Add hreflang only for genuine language / regional alternatives.
- [ ] Ensure internal links expose important pages and use descriptive anchors.

## 4. On-page content

- [ ] Write a unique, descriptive title for each important page.
- [ ] Write a useful meta description that accurately previews the page.
- [ ] Use one clear main heading and a logical heading hierarchy.
- [ ] Answer the searcher's task quickly; avoid generic filler intros.
- [ ] Demonstrate first-hand expertise, process, evidence, limitations, and useful detail.
- [ ] Use original images / diagrams where they explain something.
- [ ] Add descriptive alt text for meaningful images; empty alt for decorative images.
- [ ] Add contextual internal links and relevant authoritative external sources.
- [ ] Keep claims factual and supportable; do not invent credentials, reviews, or guarantees.
- [ ] Review content for clarity, usefulness, originality, and maintenance needs.

## 5. Local SEO

Only run this section when the business serves a real geographic market.

- [ ] Confirm exact public business name and consistency with real-world branding.
- [ ] Confirm address vs service-area business setup; do not publish a private address improperly.
- [ ] Ensure Google Business Profile details are accurate and eligible.
- [ ] Select the most accurate primary category; add only relevant secondary categories.
- [ ] Keep hours, phone, website, services, attributes, and service areas accurate.
- [ ] Build genuinely useful location/service pages; avoid mass-produced near-duplicate city pages.
- [ ] Maintain consistent business information across important directories.
- [ ] Encourage genuine customer reviews without incentives or review gating.
- [ ] Respond professionally to reviews; never fabricate reviews or suppress legitimate feedback.
- [ ] Add real, current photos that represent the business.
- [ ] Track calls, direction requests, website clicks, leads, and qualified conversions.
- [ ] Never claim a map-pack position without a defined location, device, query, and measurement date.

## 6. Structured data and trust

- [ ] Use the schema type that matches visible page content.
- [ ] Validate structured data and fix critical errors.
- [ ] Do not mark up hidden or misleading content.
- [ ] Use organization / local business details only when accurate.
- [ ] Make contact, policies, authorship, and business identity easy to verify.

## 7. Measurement

- [ ] Establish baseline before changes.
- [ ] Track impressions, clicks, CTR, average position, indexation, and conversions.
- [ ] Segment branded vs non-branded and local vs non-local queries.
- [ ] Annotate changes and evaluate over an appropriate time window.
- [ ] Report what changed and what the data can / cannot establish.
- [ ] Do not promise a guaranteed ranking or fixed time-to-rank.

## Deliverables

SEO audit, intent map, page recommendations, technical fixes, local data checklist (if applicable), content briefs, and a measurement plan.

## `/improve seo` — search growth refinement mode

- [ ] Establish current indexation, search performance, target queries, and conversion baseline where data is available.
- [ ] Audit intent-to-page mapping, cannibalization, thin content, internal links, metadata, canonicals, sitemap, and crawlability.
- [ ] For local SEO, verify real business details, service areas, categories, and location-page usefulness.
- [ ] Prioritize issues that block discovery or mismatch user intent before cosmetic metadata tweaks.
- [ ] Improve content with original, accurate expertise—not keyword padding or mass-generated location pages.
- [ ] Validate structured data against visible content.
- [ ] Check accessibility, mobile usability, and performance impacts.
- [ ] Track changes and report observed data separately from hypotheses.

Never promise rankings, fabricate business details, or manufacture reviews and backlinks.
